# Contributing

Use Node.js 22 or 24. No runtime or development dependencies are required.

```sh
npm test
npm run check
npm pack --dry-run
```

Keep tests deterministic and offline. Report an observable routing failure with a synthetic input and expected outcome. Model additions and threshold changes need current official documentation and representative evaluation, not a single favorable example. Preserve explicit choices, public-input gates, bounded transport, and truthful execution receipts.

Before release, inspect the staged diff and archive for personal paths, secrets, local logs, and task context. Keep `package.json` and `POLICY_VERSION` synchronized. Tag a CI-passing commit and document behavior and limits in the GitHub release.
